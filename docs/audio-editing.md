# Android 播放进度与本地波形剪辑

开发日期：2026-10-02。基于 GetAudio `00a1a0b`，实现版本为 `148161f` 的 0.6.0 功能提交，Android 开发版本 0.6.0 / versionCode 14；服务端接口不变。这是实现说明，不代表已安装到手机或已完成真机验收。

## 使用

播放栏增加可拖动进度条，显示已播放时间与总时长。松手后才执行跳转，目标时间提示约 1.2 秒后隐藏；跳转保留播放/暂停状态。

在音频的三个点菜单选择「剪辑音频」。进入页面后暂停普通播放器，剪辑页独立播放。真实波形由 Android MediaCodec 解码 PCM 生成，最多保存 2400 个峰值桶；支持放大、缩小和移动视窗。点击波形定位播放，拖动两端手柄调整当前保留区间，也可使用范围滑块、手动输入 `分:秒.毫秒`，或把当前播放位置设为起点/终点。

选中的是保留内容。多个片段不允许重叠，可以相邻；试听和导出均按原始时间顺序拼接。片段列表可切换、移除；添加片段会寻找未选择的时间区间。默认整个文件是第一段，需要缩短或移除后才能添加其他段。

「播放原音频」播放完整原始内容；「试听剪辑结果」连续播放所有保留片段。改变片段后会暂停旧的试听结果。应用退到后台时剪辑播放器暂停。

剪辑使用手机本地源文件快照，避免后台同步下载改变正在编辑的内容。导出使用 Media3 Transformer 1.3.1，输出 AAC/M4A；不能把输出承诺为始终无损，实际转码由输入格式和 Transformer 路径决定。输入格式是否可解码取决于设备，失败时提示错误，不覆盖原记录。输入毫秒时间不等于任意设备都具备样本级剪辑精度。

## 保存与同步

- 默认另存为新音频：独立随机负数 ID、独立文件路径、独立作品编号，标题允许重复。保留原类别，收藏默认关闭；不自动加入播放列表。
- 覆盖本地音频：确认后保留记录 ID、收藏、类别和播放列表引用，更新标题、实测时长、大小、格式、SHA-256。正在播放的该记录替换音源后暂停在开头。
- `locallyEdited` 是内部同步保护状态；三个点菜单中的剪辑入口显示「本地剪辑版」。`sourceTrackId` 记录最初的本地/服务器来源 ID，作品来源 URL 保留。
- 服务器更新不覆盖本地剪辑文件、标题、时长和哈希；服务器 tombstone 不删除本地剪辑记录及播放列表引用。原本同 ID 的服务器记录不会自动另加一条。
- 本地剪辑文件丢失时，不自动下载服务器原版冒充剪辑结果。
- 覆盖的服务器记录提供「恢复服务器原版」：确认后读取服务器最新元数据、下载并核验大小/哈希，再替换本地版本。服务器原记录不存在时失败且保留剪辑版。负数 ID 的本地记录不提供此入口。

导出先生成临时完整文件并实测时长，再复制到唯一的新路径，最后提交数据库记录；原文件不会在导出失败时被覆盖。数据库提交后更新播放队列，再清理旧文件。进程异常终止可能留下未引用的临时文件，但不会在提交前破坏旧文件。缓存快照退出剪辑页时清理。

Room 从 v5 升至 v6，仅添加 `locallyEdited` 和可空 `sourceTrackId`，不清空旧库。

## 验证范围

JVM 回归覆盖片段排序/拼接时长、重叠及越界拒绝、时间解析、同步保留剪辑元数据，以及原有播放列表等规则。构建和单元测试不能验证设备编解码器、波形触摸或 Room 真机迁移。

真机验收需要：

1. 从旧版升级，检查音频、收藏、类别及列表保留。
2. 播放中及暂停时前后拖动进度，检查跳转和短暂提示；切换曲目后进度重置。
3. 打开五分钟音频，播放并选取中间片段，缩放后微调边界；选择两个不重叠片段，试听是否按顺序播放且停在末尾。
4. 分别对 AAC/M4A、MP3、FLAC、Opus 测试设备实际解码、波形和导出；检查输出实际时长与可播放性。
5. 同名另存两条剪辑记录，确认都能加入列表；覆盖正在播放的曲目，确认暂停到开头且列表关系保留。
6. 剪辑服务器音频后同步更新和删除，检查本地文件、时长与列表不变；恢复原版检查文件哈希，模拟失败检查剪辑版仍完整。
7. 取消退出、应用切后台、低存储及中断导出，检查未保存修改不替换原文件。

本轮验证：Android `testDebugUnitTest` 38 项通过，`assembleDebug` 成功；Python 138 项通过。APK 签名校验成功，包名 `com.getaudio.app`，版本 0.6.0 / code 14。用 SQLite 临时数据库核对生成的旧 v4 表结构经 v4→v5→v6 SQL 升级后与 Room 生成的 v6 完整表结构一致，并检查 v5→v6 保留已有记录及默认值；这不替代设备上的 Room 升级验收。当前未连接 Android 设备或模拟器，尚未执行真实波形、编解码及交互验收。
