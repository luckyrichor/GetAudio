# 0.6.2 页面操作、诊断归档与批量删除

## 页面行为

- 提取页的“粘贴剪贴板”和“清空”复用现有带边框、底色的 AreaButton。
- 提取结果与提示分开：提示在显示前消费。离开页面再返回，不重复显示已消费的成功或失败提示；离页期间完成的新任务，在首次返回时显示一次。
- “我的”移除类别管理入口；音频库的类别页保持可用。
- 全部音频和类别内音频支持长按进入选择，左侧复选框、已选数量、全选、取消和删除。全选只覆盖当前筛选结果/当前类别；变更范围时清除隐藏的选择。选择期间不播放或打开音频菜单。删除前确认数量。

## 删除一致性

TrackRepository.removeAll 在事务内删除音频元数据及全部 playlist_items 引用，云端正数 ID 写入本机删除屏蔽表，避免同步又导入。按 500 项分批绑定，避免 SQLite 参数上限。事务成功后在同一文件锁内删除本地音频文件，再清理播放器队列及空队列定时器。已确认删除的事务、文件及播放器清理在 NonCancellable 生命周期内执行，切页不会留下半完成状态。

本地提取与落库同样遵守文件锁，避免删除清理误删同时重新提取的同路径文件。文件锁在等待播放器前释放，避免与播放器下载锁形成互相等待。本次删除只作用于手机，未调用服务器删除接口。

## 日志

调试和正式构建均启用应用私有 diagnostics/ 归档。每个提取或操作单独记录版本、时间、类型、状态及步骤；提取成功和失败都保留。网络请求仅记录方法、HTTP 状态或异常类型，不记录 URL、请求/响应内容、身份及头信息；播放器错误记录错误代码。云端同步及音频库操作保留末端结果；提取任务保留逐步诊断和最终原因。

单线程后台队列有序写入，失败计数常数更新。完整失败导出在 IO 线程等待先前写入完成，仅读取失败和中断任务；不会因一次成功覆盖早先失败。重启时未完成任务标为中断。过滤完整 HTTP 地址及 Cookie、Authorization、password、token、session、api_key 等敏感字段所在消息；应用禁止系统备份。

目前不自动清理历史记录，按用户要求保留所有任务。日志存储占用会随使用增长；进程被强制结束时，尚在后台队列的最后少量消息可能未落盘。旧版本只有最后一次内存记录，无法追溯恢复更早的日志。
