# 0.9.1–0.9.4：库页排序、剪辑页重构与外观精简

0.9.0 之后没有新平台链路，全部是手机 UI 与交互：库页多了序号、手动排序和字段排序，剪辑页三个按钮重做，队列拖动放宽到长按整行，外观页砍掉冗余控件。四个版本连续提交，版本号 29–32。

## 库页排序

### 手动顺序存在 `sortIndex`

`TrackEntity` 新增 `sortIndex: Long = 0`，Room 版本 8→9，迁移只加一列：

```sql
ALTER TABLE tracks ADD COLUMN sortIndex INTEGER NOT NULL DEFAULT 0
```

`0` 表示「还没手动排过」，查询按 `ORDER BY sortIndex ASC, addedAtMs DESC, id DESC` 排序，所以新入库的音频自然落在顶部，不会因为手动排过别的条目就沉底。

拖动落库走 `TrackRepository.reorderLibrary(visibleIds, newVisibleOrder)`：

- 先校验两组 ID 集合完全一致，长度或内容不符直接放弃，不写库；
- 按当前顺序取出全库 ID，只把**可见槽位**替换成新顺序。搜索或按类别筛选时拖动，只会重排当前看得见的那些，被筛掉的条目保持原位；
- 全库重新编号 `1..N`，单事务提交。

### 只有「手动」能拖

排序字段有五档：文件（按大小）、手动、时间、时长、名称。只有 `MANUAL` 使用 `sortIndex` 的原始顺序，也只有它允许拖动；切到任何一个字段排序，`dragEnabled` 直接关掉 —— 按时间排好的列表再去拖动没有意义，松手就会被排序覆盖。

拖动手势是**长按整行**触发（`detectDragGesturesAfterLongPress`），不是单独放一个把手。0.9.1 曾用左侧把手，0.9.2 去掉了：把手和「更多」在可点区外面，长按把手会先触发多选、把手随即消失，用户会以为「只能多选删除、拖不动」。

代价是多选入口必须搬家 —— 现在从「更多 → 多选」进入，进入时带上当前这一条；类别视图里的小列表仍保留长按多选（`longPressSelects`）。

### 排序控件两段式

0.9.2 是点一下循环切到下一档，档位一多就要点好几下才知道自己在哪档。0.9.3 改成：

- 点左侧字段区：当前字段在正序/倒序之间切换，手动档没有方向，弹提示条；
- 点右侧箭头：展开字段下拉，当前项后面标「（当前）」并带对勾；
- 每个字段自带默认方向（名称默认正序，其余默认倒序）。

时间排序里 `addedAtMs <= 0` 的旧记录统一压到末尾，并显示「时间未记录」，不伪造历史日期。

### 序号显示

- 0.9.1：行首裸数字，`widthIn(min = 8.dp)`，并补了「作者 · 时长」一行、入库时间单独一行 —— 一行塞不下完整的「年-月-日 时:分」。
- 0.9.3：序号左对齐贴边、放大到 18sp，两位数自然撑开。
- 0.9.4：改成 22dp 高的主色实底小圆标，12sp SemiBold 反白数字。原先「正在播放用实底、其余用 10% 淡底」两端不一致，现在统一实底，语义重复的 3dp 正在播放竖条一并删掉。

### 队列拖动（`ReorderableQueue`）

与库页逐步对齐，两种拖法都支持：

- 直接按住左侧把手上下拖，不用先长按；
- 长按任意一行再拖，可点面积大，小屏更好操作。

拖动过程只改本地草稿，松手才落库；面板关闭或队列被外部改动时安全取消，不写入半成品顺序。

## 剪辑页重构

三个按钮从左到右：

1. **播放原音频** —— 每次从 0 开始，不是从上次停下的位置续；
2. **暂停/继续** —— 纯图标 `FilledIconButton`，播放中显示 Pause，否则 PlayArrow；
3. **播放剪辑片段** —— 同样从头播放保留片段，按原时间顺序连续播放多段。

按钮下面的说明文案随状态切换：预览中提示「正在播放保留片段，按原时间顺序连续播放；用暂停/续播按钮可停在当前位置」，否则提示「边听边选择起点和终点；点波形可跳到该位置」。

### 波形缓存（`WaveformCache`）

波形靠解码整条音轨算，长文件要几秒。现在算完写一份到 `files/waveforms/<trackId>.bin`：

- 文件格式：4 字节小端 bucket 数量 + 每个 bucket 一个 float；
- 读缓存时 bucket 数或文件长度对不上就当失效，重新解码；
- 先写 `.tmp` 再改名，避免写一半被杀留下半个坏缓存；
- 覆盖保存、删除音频时调用 `forget()` 清缓存 —— 内容变了，旧波形不能再用。

首次进入仍是「边解边画」，之后同一文件直接读缓存。

## 返回键与背景层

- 「我的 → 账号管理 / 登录 / 外观 / 音频助手」四个子页都接了 `BackHandler`：系统返回键与左上角箭头走同一条路，回到「我的」而不是直接退出应用。
- 类别视图的 `BackHandler` 优先处理选中态与多级类别，先退选择、再回上一级类别。
- 助手页内容区改为 `uiSolidPage()` 铺实底、消息卡片用 `uiCardColor()`，自定义背景图只在卡片缝隙和页面边缘露出来，消息不再压在花纹上看不清。

## 外观页精简

- 删掉页内预览卡：实际效果在列表页一眼可见，预览卡只是让页面变长。
- 删掉「压暗程度」滑杆：遮罩固定 `MIN_SCRIM = 0.04`，顶部略重、向下渐轻，由 `BackgroundScrim` 内置。
- 只留「卡片不透明度」0.12–1.0，默认 0.58，100% 为完全不透明；`LocalCardAlpha` 往下传，卡片、分隔线、分组底色一起变。深色主题下底色再抬 0.16，避免白字压在透光深底上发花。
- 根 `Column` 补 `verticalScroll`，否则新加的滑杆会被底部导航压住。
